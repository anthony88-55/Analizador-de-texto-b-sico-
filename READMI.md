# Analizador de texto

## Descripción
Proyecto con metodos string enfocados al analisis de una frase.
Se usuaron metodos y funciones como:
- Input para ingresar la frase a analizar.
- Len para calcular la longitud de la frase.
- Replace para reemplazar valores especificos.
- Count para contar las coincidencias que se querian identificar.
- List para hacer la conversión de datos a tipo lista.
- Split para dividir la cadena de texto.
- Join para unir los valores de una lista y formar una oración.
- Swapcase para pasar los caracteres que esten en minúscula a mayúscula o viceversa.
